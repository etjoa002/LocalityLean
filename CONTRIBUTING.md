# Contributing

Problem reports and suggestions are welcome as GitHub issues.

This repository is the public copy of a development repository and is updated from it as the
work progresses. A pull request is reviewed there; if accepted, it is applied with credit to its
author and appears here with the next update, and the pull request is closed.

Contributions must contain no unfinished proofs (`sorry`), no added axioms and no unchecked
computation (`native_decide`), and must follow `CONVENTIONS.md`. If you used AI tools, say so in
the pull request; you remain responsible for what you submit.
